ESP32-S2 PS5 Offline Relapse Exploit Host/Runner

with itsPLK's PS5 Payload Manager and added support for Y2JB method

Flashes the ESP32-S2 board with a 100% offline version of the PS5 Relapse Exploit and provides the network access point connection the console needs and 100% offline.

Launch the user guide and the exploit should go on its own. On success, the elfldr will be running on its usual port so if you want to push from a PC or something you can.

The only payload, aside from the two for the initial exploit, that is included is the pldmgr.elf.

This does not cache in the browser so hopefully if the chain fails in the user guide, you can restart the console without it hanging.

While improvements have been made with speed, it still is not as fast as using router or something for the network connection but for me, the trade off of keeping my console actually offline is pretty worth it.

I have only tested on 13.42 but included all of the existing offsets for supported firmware. I think this was one of Sonic-Iso's hosts from some point in time with some of my edits made along the way.

NOTE: Make sure to close anything using your devices com port (e.g. Serial monitor) and you might ave to hold the boot button when clicking install. It will tell you.
